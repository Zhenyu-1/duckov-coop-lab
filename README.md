# 鸭科夫联机实验室 / Duckov Coop Lab

> 未完成 · 持续更新 · 源码云端备份

本仓库只保存源代码，用于云端备份和阶段性留档，**不是完整项目，也不是可运行发行版**。

## 当前只包含

- `server/src/`：C++ 服务端源码
- `server/CMakeLists.txt`：服务端构建入口
- `client/`：C# 协议库源码
- `mod/`：Unity 客户端 Mod 源码（`.cs` / `.csproj`）
- `README.md`

## 不包含

- 游戏导出的数据、内容表和地图
- 客户端内容快照、配置文件和依赖 DLL
- 预编译 DLL / EXE / ZIP
- 测试、工具、构建脚本和安装包
- 完整可运行的项目资产

## 说明

- 项目仍在缓慢开发中，代码结构、接口和功能都可能变化；
- 本仓库不提供安装、构建或运行支持；
- 如需构建或运行，需要自备正版游戏和相应数据；
- 本项目为非官方项目，与 Team Soda 及《逃离鸭科夫》官方无隶属关系；
- 最新开发保留在本地，这里只做阶段性源码快照。

如果你只是看到这个仓库：这是一个实验性联机项目的源码备份，尚未完成，不建议直接用于生产或二次分发。
